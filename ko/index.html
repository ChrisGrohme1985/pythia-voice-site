자주 묻는 질문

Pythia Voice의 가격은?

7일 무료 체험(또는 3,000단어) 후 Google Play를 통해 월 4.99 유로 또는 연간 39.99 유로. 이에는 받아쓰기, 음성 메시지, 음성 인식이 포함됩니다. Google Play에서 언제든지 해지 가능; 구독은 결제 기간 끝까지 유지됩니다.

계정이나 API 키가 필요한가요?

아니요. 인식은 서버에서 실행됩니다. 이미 자신의 Groq 키를 가지고 있다면 설정에서 입력할 수 있습니다.

Pythia Voice를 한 번 샀습니다. 무엇이 달라졌나요?

없습니다. 라이선스는 유효하며 이전과 마찬가지로 자신의 Groq 키로 작동합니다. 구독은 필요하지 않습니다.

녹음은 어디로 가나요?

오디오와 텍스트는 서버를 통해 Groq로 전송되어 변환되고 정리됩니다. 서버도 앱도 이를 저장하지 않으며, 제3자에게 전달하지 않습니다.

앱이 왜 접근성을 요구하나요?

그래야 키보드 위에 버튼을 표시하고 입력 중인 입력란에 텍스트를 넣을 수 있습니다. 읽는 것은 그 입력란뿐입니다.
동영상: 접근성 서비스의 용도와 켜는 방법 (1분, 영어)

오프라인에서도 되나요?

아니요. 인식에는 인터넷 연결이 필요합니다.

iPhone이나 Windows 버전이 있나요?

아직 없습니다. 지금은 Android 전용입니다.

음성 메시지는 어떻게 사용하나요?

WhatsApp이나 다른 메신저에서 음성 메시지 메뉴를 열고 공유를 선택한 뒤 Pythia Voice를 고르세요. 앱이 텍스트로 변환해 분 단위로 나눠 보여 주며, 복사하거나 공유할 수 있습니다.

음성 메시지는 얼마나 길어도 되나요?

25MB까지의 파일이 지원되며, 이는 여러 시간 분량의 음성입니다. 3분짜리 메시지는 몇 초면 됩니다. Groq는 자체 제한을 두며 변경할 수 있습니다.

계정도 없고 API 키도 없습니다. 좋아한다면 Pythia Voice Pro로 계속하세요.
